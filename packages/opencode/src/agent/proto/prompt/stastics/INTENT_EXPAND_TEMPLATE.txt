### 标注说明
- 🔴 不可改：页面壳层结构，由布局规则决定，不能修改
- 🟡 可改：具体内容，根据用户意图填充
- 🔵 可选：根据页面蓝图决定是否需要该区域
- 🟢 main内容区：以下所有内容均可根据用户意图自由修改和填充
- body下只能有main(必须)，禁止放其他节点；移动端不使用aside侧边栏，侧边导航通过Drawer实现
- footer放在root的children里，与header、body并列，在body下方；footer必须是叶子节点，不能有children
- infoBar必须放在root的children里，与header、body并列，不能放到body下
- 移动端不使用rightPanel，右侧面板内容通过Drawer或弹窗展示
- layout 字段表示布局方向，可选值为 "horizontal"（水平排列）或 "vertical"（垂直排列），必须根据子节点的实际排列方向决定
- layoutDescription 字段表示子元素的详细布局方式，只能取以下枚举值：`default`（默认）、`justify-between`（两端对齐）、`equal-width`（等宽等距排布）、`stack`（垂直堆叠，子元素占满宽度纵向排列）、`tabs`（标签页切换布局）。禁止使用其他值
- containerType 字段表示容器类型，可选值为 "Region"（独立区块，渲染为Section组件）或 "Card"（卡片容器，渲染为Card组件），不设则默认为普通div
- 用户意图中 `{{独立区块}}` 表示该节点是独立区块，需要设置 containerType:"Region"。例如："左侧区域{{独立区块}}"表示左侧区域节点的containerType为Region
- style 字段只包含纯样式关键词，如 "固定宽度500px,固定高度300px" 等。布局方向和布局方式信息放 layout 和 layoutDescription 字段，不放 style。禁止在 style 中重复 containerType 的信息（如不要放"独立区块"、"卡片"）
- 详细的内容描述必须放在 description 字段中，不能放在 style、layoutDescription 或 containerType 中
- 不使用 annotations 字段
