# Annotations 字段 — 通用规则

蓝图中节点的 `annotations` 字符串数组字段，用于原样保留用户意图中 `{{...}}` 标注的语义约束。

## 标注值与语义

| annotation | 含义 | 组件选择 | 样式 |
|---|---|---|---|
| `独立区块` | 页面中的独立视觉区块 | `Section` | 内置 bg-surface-container-highest + shadow-sm + rounded-xl + p-[1.5rem]，不可手动添加 |
| `卡片` | 卡片容器 | `Card` | bg-surface-container-highest + shadow-sm + rounded-xl + p-* |
| `二级卡片` | 卡片内的嵌套子卡片 | `Card` | bg-surface-variant + rounded-[16px]，不用 shadow |
| `水平排列` | 子元素水平排列 | 同节点类型 | flex flex-row |
| `垂直排列` | 子元素垂直排列 | 同节点类型 | flex flex-col |
| `宽度Npx` | 固定宽度约束 | 同节点类型 | w-[Npx] shrink-0 |

## 通用原则

1. annotations 中的值必须原样保留，任何 agent 禁止省略、改写或合并
2. 一个节点可以有多个 annotation（如 `["独立区块", "高度300px"]`）
3. `独立区块` 表示该节点是独立视觉区块，下游会自动派生 isRegion:true 和 Section 组件
4. 下游 agent 在选择组件和样式时，必须优先遵循 annotations 的约束，而非自行推断
5. 新增标注类型时，必须在此表中补充对应的语义和组件映射
