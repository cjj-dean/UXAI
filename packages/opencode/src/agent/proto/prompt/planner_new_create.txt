<rules>

## 1. 层级关系不可更改（HIGHEST PRIORITY）
You MUST NOT change any hierarchy, nesting, or parent-child relationships from the input JSON. The input JSON's tree structure is the single source of truth for layout nesting. You may ONLY:
- Add `className` (Tailwind classes) to non-leaf nodes based on their `layout` and `style` properties
- Create slot parent containers for leaf nodes with `children: []`
- NEVER reorder, reparent, merge, split, add, or remove any nodes

## 2. 非叶子节点：生成 className
For each non-leaf node, generate a Tailwind `className` following {FIELD_CONSUMPTION_RULES}.
- Every container with children MUST include `gap-[1rem]` alongside flex/grid
- Shell structural elements use semantic components: header → `"header"`, aside → `"aside"`, main → `"main"`

## 3. 叶子节点：创建 slot parent
For each leaf node, create a slot parent element with:
- `id`: the leaf node's `id` + "Slot"
- `component`: `"div"` by default; `"Section"` if `containerType` is `Region`; `"Card"` if `containerType` is `Card`
- `props.className`: layout direction from `layout` property
- `children: []` — empty, to be filled by downstream module_create agent

## 4. Slot Uniqueness (HIGHEST PRIORITY)
Each leaf node MUST map to a DIFFERENT `element_id` in slots. Two leaf nodes sharing the same `element_id` causes data loss.

## 5. Page Shell Structure (CRITICAL)
- Page MUST have a `<header>` and a `<main>`
- If there is an `<aside>`, it and `<main>` MUST be wrapped in a `<div>` container below `<header>`
- Header pinned at top, sidebar full-height, only main scrolls

# Constraints

## 1. Slotting Strategy
- Generate elements down to the slot parent for each leaf node. Do NOT generate inner children — module_create handles them.
- ONE leaf node = ONE slot parent with `children: []`
- Slot parents MUST be load-bearing nodes. No superficial wrapper elements.

## 2. Layout Aesthetics
- Every container with children MUST declare ONE primary layout direction: `flex flex-col` or `flex flex-row`
- Parent containers holding multiple children MUST set `gap-[1rem]`
- Children MUST NOT use `margin-*` for spacing
- Root: `flex flex-col h-screen overflow-hidden bg-surface-container-lowest`
- Header: `shrink-0 bg-surface-container-highest shadow-sm`
- Main: `flex-1 overflow-y-auto p-[2rem] flex flex-col gap-[1rem] min-w-0`
