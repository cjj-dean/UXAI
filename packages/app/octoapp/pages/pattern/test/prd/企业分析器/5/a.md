整体布局结构
页面自上而下分为两部分：顶部全局导航区、主体内容区。
顶部全局导航区
整栏采用 Flex 横向排布布局；最左侧为汉堡菜单图标，紧随其后是系统 Logo 与系统名称文本 iMaster NCE - 传输网管；系统名称右侧横向排布三组带图标导航菜单项，文本依次为：数据入库、报表已生成、作业已校验。
导航栏最右侧功能区从左至右依次为：身份文本 系统操作员、问号形状帮助图标、铃铛形状消息通知图标、太阳形状主题切换图标、圆形用户头像图标，头像旁展示登录用户名 admin。
主体内容区
位于顶部导航栏正下方，是页面核心业务区域，内部划分为多个功能子模块。

左上角为一级横向选项卡布局，共有三项标签，前两项未选中（灰色样式），第三项选中高亮；一级页签容器内部包含两处上下排布子模块：一处是可展开收起面板组件，一处为二级选项卡；二级选项卡共三项标签，第一个标签选中高亮，剩余两个未选中。
二级选项卡下方为操作区域，采用 Flex 两端分散对齐布局，分为左右两个子区域；左侧子区域水平排布下拉单选组件与搜索输入组件；右侧子区域水平排布两个按钮：普通文本按钮、蓝色填充样式主按钮。

主体数据表格区
实现支持行选中、行展开折叠、内嵌详情视图的数据表格。
表头字段（从左至右）：占位留白（用于对齐展开箭头）、全选复选框、设备名称、设备类型、源目 IP 及端口、所属业务、协议类型、MAC 地址标识、转发状态、责任人、健康状态，以及最右侧的操作列 操作。
第一行（设置为展开状态）：起始为向下的展开指示箭头和复选框。单元格数据依次为：Core-Switch-01、核心交换机、192.168.1.1/24->10.0.0.5/8:8080、核心骨干网、TCP、00:1A:2B:3C:4D:5E、正常。其后两列文本 张工程师 和 运行正常 需带有前置状态圆点。最右侧操作列需放置四个通用图标按钮（文档、编辑、删除、设置）。

行展开数据详情面板。面板内部呈两行三列的矩阵，排布六个图表模块。
图表1（左上）：蓝色实心竖柱状图，标题 入方向流量统计 (Mbps)。X轴为 eth1/1, eth1/2 等10个接口分类，Y轴刻度范围0至1000。
图表2（中上）：蓝色实心竖柱状图，标题 出方向流量统计 (Mbps)。X轴为 eth2/1, eth2/2 等10个接口分类，Y轴刻度范围0至1000。
图表3（右上）：横向进度图，标题 Top 5 访问源 IP 排名。
图表4（左下）：横向进度图，标题 Top 5 目的 IP 排名。
图表5（中下）：横向进度图，标题 高频访问会话连接（标题后带信息提示图标）。
图表6（右下）：横向进度图，标题 各节点实时吞吐量。

第二至五行（设置为折叠状态）：每行起始为向右的折叠箭头和复选框，操作列均同第一行包含四个图标。
第二行数据：Access-Switch-02、接入交换机、10.1.2.3/24->172.16.0.5/16:22、办公区网络、UDP、--、告警、李管理员（带状态点）、丢包率高（带状态点）。

第四行数据：Firewall-Active、核心防火墙、172.16.8.9/16->10.10.3.5/24:443、安全防护区、IPsec、--、阻断、赵安全员（带状态点）、拦截生效（带状态点）。
