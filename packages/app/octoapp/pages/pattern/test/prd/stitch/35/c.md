精准细节型：

开发一个名为SupportHub的客服支持与工单处理系统原型。页面采用顶部导航、左侧边栏、中间对话区、右侧属性栏的多栏复合布局。顶部导航栏从左到右依次为带有提示词“搜索工单、客户或知识库...”的全局搜索框、消息图标、设置图标，右侧展现大标题“工单处理与回复 (Ticket Processing)”。左侧边栏顶部为系统标志“SupportHub Modern Support & Marketing”，中间垂直排列Inbox、Knowledge Base、Campaigns、Audience、Builder五个菜单项，其中Inbox为高亮选中状态，底部固定展示当前座席“张小明 (Agent) 高级客服专员”的头像与文字信息。

主内容区从左至右由三个纵向功能块组成：
最左侧为客户档案与历史模块。顶部卡片展示客户李京生(Jingsheng Li)的头像、姓名、注册年份，并带有企业版用户和高价值两个胶囊标签；中间为SLA倒计时模块，标题为“距离 SLA 超时”，中心由一个数值为45m的环形进度条图表呈现，下方配有红字“紧急响应需求”；底部为历史往来列表，包含工单12890已结案和工单13002处理中两个时间线节点，并带有文本摘要和具体日期。

中间为核心工单对话流模块。顶部居中显示文本“工单创建于 2023-11-29 09:45 (Web 渠道)”。下方依次堆叠三条对话卡片：第一条是客户李京生于09:46发送的白色背景留言，文本为“你好，我们的生产环境 API 目前持续报错 429 Too Many Requests。我们已经升级了铂金套餐，按理说不应该受到现在的频率限制。请立即核查并调高限额。”；第二条是客服张小明于10:15发布的浅黄色内部笔记卡片，带锁头图标，内容为“经验查，该用户的账户套餐同步在计费系统中存在延迟。已通知开发团队手动触发同步脚本。—— 张小明”，右下角标注仅员工可见；第三条是客服张小明于10:20回复的深蓝色背景卡片，文本为“尊敬的李先生，您好。非常抱歉给您的生产环境带来影响。我们已经定位到由于套餐同步异常导致的限制问题。技术团队正在手动刷新限额，预计 5 分钟内生效。我会为您持续关注。”。对话流最下方是一个富文本编辑器，顶部集成加粗、倾斜、链接、附件、表情工具栏，中间是带提示词“在这里输入您的回复内容...”的输入框，底部左侧是一个未勾选的“作为内部笔记发送”复选框，右侧并列白底的“存为草稿”按钮与蓝底的“发送回复”按钮。

最右侧为工单属性控制模块。顶部为工单属性卡片，包含三个垂直排列的下拉选择框，分别为优先级（当前选中带红点的紧急 Urgent）、工单分类（当前选中技术支持 / API）、负责人（当前选中带头像的张小明 Me）。中间为快捷宏操作列表，包含三个可点击的水平矩形块，主副标题分别为：API 故障确认（自动回复定位中并通知技术部）、套餐升级指引（发送铂金权限说明文档）、工单升级 Escalate（转发至二线技术专家）。底部为标签模块，展示#API_Error和#Production两个带删除按钮的灰色标签，并提供一个+添加标签的交互按钮。
