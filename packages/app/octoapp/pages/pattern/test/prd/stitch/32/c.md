精准细节型：

开发一个人才招聘追踪(ATS)系统界面。

1. 侧边栏：顶部显示Global Ops及HR Administration，导航项依次为Dashboard、招聘看板（选中态）、Team Schedule、Attendance、Leave Management、Reports，底部包含Clock In/Out大按钮、Settings与Support。
2. 顶部区域：居中为带搜索图标的“搜索候选人、职位或部门...”输入框，右侧有通知、帮助和头像。
3. 筛选栏：主标题下包含职位、技术部、负责人三个下拉筛选，右侧显示“内推”选中标签及“清除全部”按钮。
4. 看板结构：
* 简历初筛列（12人）：卡片需展示姓名、职位、渠道标签（如Referral）、评价标签（如Strong Hire）及时间戳（如3天前）。
* 笔试阶段列（8人）：卡片增加五星评分组件和笔试分数展示（如88分）。
* 面试阶段列（5人）：需支持状态角标（如初试/复试）。重点展示面试预约块，包含具体时间（今日 14:00）、面试类型及面试官姓名，并显示具体的面试渠道（如Dribbble、官网申请）。
5. 视觉逻辑：所有卡片采用纵向堆叠，内部信息分行排布，确保不同阶段的信息颗粒度有明显区分。
