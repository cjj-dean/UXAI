  生成一个企业级后台管理与数据监控页面。页面布局采用经典的顶部导航栏、左侧菜单栏和右侧主内容区。

  页面结构：
  1. 顶部导航栏
  - 最左侧是产品 Logo 和平台名称：iMaster Admin
  - 中间是水平排列导航菜单项：
    - 首页
    - 资产管理
    - 数据分析
    - 报表中心（该项需高亮显示并带下划线指示当前选中状态）
    - 文档中心
    - 系统设置
  - 最右侧放置问号（帮助/说明）、方形中英文字符图标（语言切换）、用户头像。

  2. 左侧侧边菜单栏
  - 顶部左对齐显示模块名称：智能决策平台（无图标）
  - 菜单分组清晰，使用图标 + 文本
  - 菜单选项示例：
      - "用户权限管理"
      - "组织架构配置"
      - "**计算资源管理**"（当前处于展开状态），其下缩进显示6个子菜单项（子菜单项没有图标，只有文本）：
          - "**物理服务器列表**"（需高亮背景显示，为当前选中项）
          - "虚拟机实例"
          - "容器集群状态"
          - "云盘存储分配"
          - "负载均衡配置"
          - "安全组防火墙"
      - "网络拓扑视图"（右侧带向右折叠箭头）
      - "性能日志分析"（右侧带向右折叠箭头）
      - "告警规则策略"（右侧带向右折叠箭头）
      - "系统巡检报告"（右侧带向右折叠箭头）
      - "工单审批流程"（右侧带向右折叠箭头）

  3. 主内容区（内部模块左对齐排布）
  3.1 标题：内容为**核心运行指标**，纯文本没有背景

  3.2 统计数据模块
  - 外层：通栏容器，有背景，圆角，内边距。
  - 内部：两个子区域水平并排排列有间距，每个子区域无背景。
    - **子区域结构**（统一结构）：左侧图片区 + 右侧数据区，两者水平排列、垂直居中对齐、等高。
      - 左侧图片区：一个抽象插画图（不要使用 icon 图标库）。
      - 右侧数据区：垂直排列，上方为标题文字，下方为数据行。
        - 数据行：flex行布局水平排列多个数据项，都是数据项之间有间距。
        - 每个数据项由两个flex行布局**同行水平排列**的**纯文本**组成：前半部分为大号加粗文字，后半部分为小号常规后缀文字，两者之间有一个空格分隔。

    - **第一个子区域**：
      - 左侧图片：绘制一个抽象的芯片/算力插画（如方形芯片 + 电路纹理）。
      - 右侧标题："**CPU与算力**"
      - 右侧数据行，包含 2 个数据项：
        - 大号 "**68.3 %**" + 小号 "使用率"
        - 大号 "**128 核**" + 小号 "总计"

    - **第二个子区域**：
      - 左侧图片：绘制一个抽象的网络节点插画（如多个圆圈连线 + 对勾标记）。
      - 右侧标题："**节点连接状态**"
      - 右侧数据行，包含 3 个数据项：
        - 大号 "**22 个**" + 小号 "在线"
        - 大号 "**5 个**" + 小号 "离线"
        - 大号 "**2 个**" + 小号 "异常报警"
